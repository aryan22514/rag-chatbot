Grounded by design

When the answer isn't there, it says so.

Ask about Tesla's stock price. Gemini knows plenty about Tesla — but the best match in your library is 46%, and the model is instructed to answer only from your passages. So it declines instead of inventing something plausible.

Under the hood

Six parts, one job each.

API

FastAPI

Upload, ask, list and delete endpoints — plus this page. Swagger docs for free.

Read

pypdf

Rebuilds readable text from the positioned glyphs inside every PDF page.

Embed

gemini-embedding-001

Turns passages and questions into 768-number vectors, tuned for retrieval.

Store

ChromaDB

A local vector database with an HNSW index for fast cosine-similarity search.

Answer

Gemini 3.8 Flash

Writes the reply from retrieved passages only, under a strict grounding instruction.

Verify

pytest

Guards the chunking contract — overlap, ordering and counts — on every run.
